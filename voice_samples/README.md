# Andrew Voice Sample — Normal 0% Speed

`andrew_0pct_sample.txt` is a short, unfinalised urban-flood survival premise written to test a more immediate narrative tone with shorter sentences and dialogue. It is a voice/pacing sample, not an approved series premise or full script.

Run `run_andrew_voice_sample.sh` from a network-enabled environment such as Kaggle. It synthesises **one continuous `en-US-AndrewNeural` take at `+0%`** and writes `voice_samples/andrew_0pct_sample.mp3`.

The `-5%` rate used for the earlier production test can make Andrew sound slower or more dragged. This 0% sample isolates the normal-speed voice before another full story is developed.
