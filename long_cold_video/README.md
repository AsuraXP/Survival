# long_cold_video — THE LONG COLD

10-minute, second-person survival short about a global freeze. Ink-and-watercolour cartoon look.

```
long_cold_video/
├── README.md          this file
├── brief.md           locked creative brief (hard rules live here)
├── script.md          narration only — 1876 words, 10:05
├── visuals.csv        micro-beat spine (slide_id, moment, moment_text, visual_prompt)
├── continuity.md      locked style + character blocks, content-moderation swaps
├── metadata.json      title/description/tags for the deliverable
├── youtube.txt        upload copy
├── STATE.md           state-machine log + declared exceptions
├── frames/            beat{slide:02d}m{moment:02d}.png  (generated by workers)
└── refs/              ARTSTYLE-ONLY reference images
```

## Pipeline
1. **Here:** script → `visuals.csv` → style anchors → parallel worker frame generation → merge → thumbnail.
2. **Kaggle:** `run_long_cold_kaggle.sh` → Edge-TTS one take with word timestamps → PIL canvas pre-padding → hard-cut concat → loudnorm → `long_cold_DELIVERABLE.zip`.

## Rules that bite
- Frames are word-reactive: durations are **outputs** of TTS timestamps, never chosen by hand.
- Hard cuts only. No crossfades, dissolves, or fades — ever.
- Reference images are style/character only, never background layout.
- No audio work in this repo.
